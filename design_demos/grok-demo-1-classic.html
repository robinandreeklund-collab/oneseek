2. Gissningslek (1–100)

Python
▶ Kopiera 
import random

hemligt = random.randint(1, 100)
gissningar = 0

while True:
    gissning = int(input("Gissa ett tal mellan 1-100: "))
    gissningar += 1
    if gissning == hemligt:
        print(f"Rätt! {gissningar} försök.")
        break
    elif gissning < hemligt:
        print("För lågt!")
    else:
        print("För högt!")
